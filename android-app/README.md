# Магия Карт — Android

A Capacitor shell around the web app: it opens
`https://tarot-ai-app-eight.vercel.app/?app=android` in a native WebView.
Inside the app the web code runs in "app mode" (`src/lib/app-mode.ts`):
no Telegram, the device signs in through `/api/app/session`
(`src/lib/app-session.ts`), Android back button, vibration and the system
share sheet stand in for the Telegram ones. The Telegram Mini App is not
affected.

- `capacitor.config.json` — app id, name, start URL, splash, system bars
- `www/` — fallback pages (`offline.html` when there is no connection)
- `android/` — the native project (generated by `npx cap add android`)
- `icon-512.png` — store icon; launcher icons and splash are in `android/app/src/main/res`

## Build

GitHub Actions (`.github/workflows/android.yml`) builds a debug APK on every
push to `feature/android` that touches this folder and publishes it as the
`android-latest` pre-release. Locally (needs the Android SDK):

```
npm ci && npx cap sync android && cd android && ./gradlew assembleDebug
```
